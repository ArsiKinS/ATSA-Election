# คู่มือเว็บเลือกตั้ง ATSA (ภาษาไทย)

## วิธีทำงาน (สั้น ๆ)
- วันเลือกตั้งใช้ **คอมพิวเตอร์กลางหนึ่งเครื่อง** ที่จุดเลือกตั้ง เจ้าหน้าที่ตรวจชื่อผู้มีสิทธิ์จากรายชื่อ แล้วให้ผู้โหวตกดโหวตทีละคน
- บัตรมี 2 ขั้น: เลือกประธาน 1 คน แล้วเลือกสมาชิกบอร์ด 3 คน (ปรับจำนวนได้) กด Submit แล้วหน้าจอรีเซ็ตให้คนถัดไปเอง
- คนที่ไม่ได้เป็นประธาน (ในกรณีลงประธาน 2 คน) จะเป็น Assistant Secretary อัตโนมัติ
- แอดมินเห็นคะแนนและเปอร์เซ็นต์ทั้งหมดหลังปิดโหวต ส่วนหน้าสาธารณะโชว์แค่ประธาน ผู้ช่วยเลขา และสมาชิกบอร์ด ไม่มีตัวเลข
- บัตรไม่เก็บชื่อ อีเมล เวลา หรือรหัสเครื่อง

## ต้องมีอะไรบ้าง
บัญชี GitHub, Vercel และ Neon (ไม่ต้องใช้ Gmail และไม่ต้องมีรายชื่ออีเมลผู้โหวตอีกแล้ว)

## ขั้นที่ 1: ฐานข้อมูล (Neon)
1. neon.tech → Create project → คัดลอก **Connection string** (ขึ้นต้น `postgresql://`) = `DATABASE_URL`
2. **SQL Editor** → วางทั้งไฟล์ `schema.sql` → Run (ครั้งเดียว)

## ขั้นที่ 2: รหัสลับ
เปิด `keygen.html` ในเบราว์เซอร์ กด Generate จะได้ `SESSION_SECRET` และ `SETUP_TOKEN` จดเก็บไว้ ห้ามขึ้น GitHub

## ขั้นที่ 3: GitHub และ Vercel
1. สร้าง repo แบบ **Private** อัปโหลดไฟล์ทั้งหมด (ห้ามมีไฟล์ `.env.local`)
2. Vercel → Add New → Project → เลือก repo → ใส่ Environment Variables 4 ตัว:
   `DATABASE_URL`, `SESSION_SECRET`, `SETUP_TOKEN`, `APP_URL` (= `https://ชื่อโปรเจกต์.vercel.app`) → Deploy
3. ตั้ง Function Region ให้ใกล้ฐานข้อมูล (Settings → Functions) จะเร็วขึ้น

## ขั้นที่ 4: สร้างแอดมิน
เปิด `/admin/setup` ใส่ Setup token + อีเมล + รหัสผ่านอย่างน้อย 10 ตัวอักษร (ใช้ได้ครั้งเดียว) แล้วเข้า `/admin/login`

## ขั้นที่ 5: ตั้งค่าในหน้าแอดมิน
- **Election and branding:** ชื่อ โลโก้ สี เวลาเปิด/ปิด/ประกาศผล (เวลามาเลเซีย) **Board seats** = จำนวนสมาชิกบอร์ดที่เลือก (3) **Ballot limit** = จำนวนผู้มีสิทธิ์สูงสุด
- **Candidates:** เพิ่มผู้สมัครทั้ง 9 คน ติ๊ก **Runs for President** ให้ 2 คนที่ลงประธาน และ **Competes for the board** ให้คนที่แข่งตำแหน่งบอร์ด
- ตั้งเวลาเปิดโหวตให้เป็นอนาคต (ผู้สมัครจะล็อกเมื่อถึงเวลาเปิด)

## วันเลือกตั้ง
1. ที่คอมพิวเตอร์กลาง เปิดเว็บ → `/admin/login` → หน้า Overview กด **Open ballot on this computer** (ระบบจะออกจากแอดมินในเครื่องนั้น และเครื่องนั้นกลายเป็นเครื่องโหวต)
2. กด F11 (หรือเปิดเต็มจอ) ให้ผู้โหวตเห็นแต่หน้าโหวต
3. เจ้าหน้าที่ตรวจชื่อจากรายชื่อกระดาษทีละคน ติ๊กชื่อ แล้วให้ผู้โหวตกด **Start voting**
4. ผู้โหวตกด Submit แล้วหน้าจอรีเซ็ตเอง (ถ้าทิ้งไว้เกิน 90 วินาที บัตรที่ยังไม่เสร็จจะถูกล้าง)
5. เลิกโหวต: ระบบหยุดรับบัตรเองตามเวลาปิด หรือเมื่อครบ Ballot limit

## โหวตออนไลน์สำหรับคนที่มาไม่ได้ (จำนวนน้อย)
1. คณะกรรมการตรวจสอบรายชื่อคนที่มาไม่ได้ก่อน
2. หน้าแอดมิน → ส่วน **Online voting (approved members)** ใส่จำนวนรหัส กด **Create codes** (สร้างเท่ากับจำนวนคนที่อนุมัติเท่านั้น)
3. ก๊อปรหัสทันที เพราะ **แสดงครั้งเดียวและระบบไม่เก็บรหัสไว้** ส่งให้แต่ละคนแบบส่วนตัว (คนละ 1 รหัส) และจดเองว่าส่งให้ใคร ระบบไม่เก็บชื่อ
4. ผู้โหวตเปิดเว็บ ไปหน้า Vote ใส่รหัส แล้วโหวตบัตรแบบเดียวกัน (รหัสใช้ได้ครั้งเดียว) ถ้ารหัสหาย กด **Cancel unused codes** เพื่อยกเลิกรหัสที่ยังไม่ถูกใช้ แล้วสร้างใหม่
5. บัตรออนไลน์นับรวมใน Ballot limit เดียวกัน ดังนั้นให้ตั้ง Ballot limit = ผู้โหวตที่หน่วยเลือกตั้ง + ผู้โหวตออนไลน์
6. ข้อจำกัด: ไม่มีใครดูตอนโหวตออนไลน์ และส่งรหัสต่อให้คนอื่นได้ จึงควรใช้เฉพาะคนที่ไว้ใจและตรวจสอบแล้ว

## หลังเลือกตั้ง
1. เทียบ **จำนวนบัตร** (หน้า Overview) กับ **จำนวนชื่อที่ติ๊กในรายชื่อกระดาษ** ต้องไม่เกินกัน
2. Results Manager หรือ Super Admin ล็อกอิน กด **Verify results** แล้ว **Publish** (หรือรอประกาศผลอัตโนมัติตามเวลา)
3. ดูคะแนนทั้งหมดและดาวน์โหลด CSV ได้เฉพาะแอดมิน
4. ถ้าคะแนนเท่ากัน ระบบจะแจ้งว่าเสมอ คณะกรรมการต้องตัดสินกันเอง

## อัปเกรดจากเวอร์ชันเดิม (ที่ใช้อีเมล)
1. Neon SQL Editor → วางไฟล์ `migrate-v2.sql` → Run แล้วตามด้วย `migrate-v3.sql` → Run (รันซ้ำได้ทั้งคู่ ถ้าเคยรัน v2 แล้วให้รันเฉพาะ v3)
2. อัปโหลดไฟล์ใหม่ทับใน GitHub (Vercel จะ deploy เอง)
3. ใน Vercel ลบตัวแปรที่ไม่ใช้แล้วได้: `BLIND_KEY_B64`, `SMTP_*`, `MAIL_FROM`
4. ผู้สมัครเดิม: เข้า Candidates กด Edit แล้วติ๊กว่าใครลงประธาน/บอร์ด

## ข้อควรรู้
ระบบไม่รู้ว่าใครยืนอยู่หน้าเครื่อง **เจ้าหน้าที่ต้องตรวจชื่อทุกคนเอง** ถ้าไม่มีคนดูแล คนหนึ่งคนอาจกดโหวตซ้ำได้
