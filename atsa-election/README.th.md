# คู่มือขึ้นเว็บเลือกตั้ง ATSA (ภาษาไทย)

ทำตามทีละข้อ ไม่ต้องติดตั้งโปรแกรมในเครื่อง ใช้เบราว์เซอร์อย่างเดียว

## ที่ต้องมี
- บัญชี GitHub, Vercel (สมัครด้วย GitHub), Neon (ฐานข้อมูลฟรี), และ Gmail ของสมาคม (ไว้ส่งลิงก์เข้าสู่ระบบให้ผู้โหวต)

## ขั้นที่ 1: ฐานข้อมูล (Neon)
1. เข้า neon.tech สมัครแล้วกด Create project
2. คัดลอก **Connection string** (ขึ้นต้นด้วย `postgres://`) เก็บไว้ = `DATABASE_URL`
3. เมนู **SQL Editor** วางเนื้อหาทั้งหมดของไฟล์ `schema.sql` แล้วกด Run (ทำครั้งเดียว)

## ขั้นที่ 2: สร้างรหัสลับ
เปิดไฟล์ `keygen.html` ในเบราว์เซอร์ (ดับเบิลคลิก) กด Generate จะได้ 3 ค่า: `SESSION_SECRET`, `SETUP_TOKEN`, `BLIND_KEY_B64`
เก็บไว้ในที่ปลอดภัย **ห้ามส่งขึ้น GitHub** และห้ามทำหาย (ถ้า `BLIND_KEY_B64` เปลี่ยนหลังเริ่มโหวต บัตรที่ออกไปแล้วจะใช้ไม่ได้)

## ขั้นที่ 3: อีเมลสำหรับส่งลิงก์ (Gmail)
1. บัญชี Gmail ของสมาคม เปิด 2-Step Verification
2. ไปที่ Security → App passwords สร้างรหัสแอป 1 อัน (16 ตัวอักษร) = `SMTP_PASS`
3. `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=465`, `SMTP_USER` = อีเมล Gmail นั้น
(Gmail ส่งได้ประมาณ 500 ฉบับต่อวัน เพียงพอสำหรับสมาคม)

## ขั้นที่ 4: ขึ้น GitHub
1. สร้าง repository ใหม่ เลือก **Private**
2. ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ใส่ (หรือใช้ GitHub Desktop) แล้วกด Commit
3. ตรวจว่าไม่มีไฟล์ `.env.local` ขึ้นไปด้วย (ในโปรเจกต์นี้ไม่มีอยู่แล้ว และ `.gitignore` กันไว้)

## ขั้นที่ 5: Deploy บน Vercel
1. vercel.com → Add New → Project → เลือก repo → ก่อนกด Deploy เปิด **Environment Variables** แล้วใส่:
   `DATABASE_URL`, `SESSION_SECRET`, `SETUP_TOKEN`, `BLIND_KEY_B64`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`, และ `APP_URL` (ใส่ชั่วคราวเป็น https://ชื่อโปรเจกต์.vercel.app)
2. กด Deploy พอได้ลิงก์จริง ให้ตรวจว่า `APP_URL` ตรงกับลิงก์นั้น ถ้าไม่ตรงให้แก้แล้วกด Redeploy

## ขั้นที่ 6: สร้างแอดมินคนแรก
เปิด `https://ลิงก์ของคุณ/admin/setup` ใส่ Setup token (จากขั้นที่ 2), อีเมล และรหัสผ่านอย่างน้อย 10 ตัวอักษร แล้วไป `/admin/login`
หน้านี้ใช้ได้ครั้งเดียวเท่านั้น หลังจากนี้ใช้ไม่ได้อีก

## ขั้นที่ 7: ตั้งค่าในหน้าแอดมิน
- **Election and branding:** ชื่อ โลโก้ สี และเวลาเปิด/ปิด/ประกาศผล (เวลามาเลเซีย) แล้วกด Save
- **Positions:** รายชื่อตำแหน่งตามลำดับ (ใส่ผู้ช่วยเลขานุการ ผู้ช่วยเหรัญญิกแล้ว แก้ได้)
- **Candidates:** เพิ่มผู้สมัคร รูป ประวัติ นโยบาย
- **Voter list:** วางอีเมลผู้มีสิทธิ์ (วางเป็นรายการได้เลย)
- **Overview:** มี QR code ให้ปริ้นหรือโชว์ให้น้อง ๆ สแกนเปิดหน้าโหวต
- เพิ่มแอดมินคนอื่นในส่วน Admin accounts เลือกบทบาทได้ 3 แบบ (Super Admin / Election Committee / Results Manager)

## ก่อนเลือกตั้งจริง (สำคัญ)
1. **ซ้อมก่อน** ด้วย Neon database และ Vercel project อีกชุด (ใช้อีเมลของตัวเองเป็นผู้โหวต) เพื่อไม่ให้ข้อมูลทดลองปนกับของจริง
2. ตรวจว่าอีเมลส่งถึงผู้โหวต (เช็กโฟลเดอร์สแปมด้วย)
3. ให้คนอื่นในทีม (หรืออาจารย์ที่ปรึกษา) ลองใช้และอ่านหมายเหตุเรื่องความเป็นส่วนตัวใน `README.md`
4. หลังเลือกตั้งจบ: กด Verify แล้ว Publish (หรือรอประกาศผลอัตโนมัติ) แล้วสำรองฐานข้อมูล (Neon มีระบบย้อนกลับข้อมูลให้)

## ถ้าผู้โหวตมีปัญหา
- **ไม่ได้รับอีเมล:** เช็กสแปม และตรวจว่าอีเมลอยู่ในรายชื่อ (ระบบจะไม่บอกว่าอีเมลนั้นอยู่ในรายชื่อหรือไม่ เพื่อความเป็นส่วนตัว)
- **ลิงก์ใช้ไม่ได้:** ลิงก์ใช้ได้ครั้งเดียวและมีอายุ 15 นาที ขอลิงก์ใหม่ได้ (สูงสุด 5 ครั้งต่อชั่วโมง)
- **ล้างข้อมูลเบราว์เซอร์ระหว่างโหวต:** ระบบออกบัตรใหม่ให้ไม่ได้เพราะไม่รู้ว่าบัตรเดิมถูกใช้หรือยัง คณะกรรมการต้องตัดสินใจร่วมกัน
